# 밑바닥부터 만드는 추론 엔진

**Rust로 배우는 AI 인퍼런스 엔지니어링**

*Building an Inference Engine from Scratch: AI Inference Engineering in Rust*

---

추론 엔진 `badak`을 Rust로 직접 만들어 LLM, 비전, 음성, 이미지 생성,
멀티모달 모델을 끝까지 돌려 보고, llama.cpp나 LiteRT 같은 실전 엔진과
성능을 비교해 차이가 어디서 오는지 하나씩 밝혀 갑니다.

> **집필 중인 책입니다.** 목차에서 회색으로 보이는 장은 아직 쓰이지
> 않았습니다. 장이 완성될 때마다 이 사이트에 게시됩니다.

## 시니어 소프트웨어 엔지니어를 위한 책이다

AI 인퍼런스 엔지니어링으로 영역을 넓히려는 시니어 소프트웨어 엔지니어를
위한 책입니다. 머신러닝 지식은 전제하지 않으며, 필요한 수학과 신경망
지식은 모두 책 안에서 다룹니다.

## 책은 일곱 부로 이루어진다

| 부 | 내용 |
|---|---|
| 1부. 기초 | 수학, 신경망, 텐서, 연산자, 모델 파일, 첫 모델 완주 |
| 2부. LLM 완주 | 토크나이저, 트랜스포머, KV 캐시, 샘플링, llama.cpp와 첫 대결 |
| 3부. 성능 | 프로파일링, 병목 계산, 행렬 곱, SIMD, 멀티스레딩, 양자화, 메모리, GPU |
| 4부. 분야별 완주 | 비전, 음성 인식, 임베딩, 이미지 생성, 멀티모달, 음성 합성 |
| 5부. 서빙 | 추론 서버, 배칭, 생성 제어와 가속, 데이터센터 규모의 추론 |
| 6부. 온디바이스 AI | 폰, 모바일 가속기, 모델 줄이기, 온디바이스 LLM, 브라우저 |
| 7부. 지평 | 프레임워크 배포의 한계, ML 컴파일러, 종합 성적표 |
