# 서문

## 이 책은 무엇을 하는가

이 책에서 우리는 추론 엔진(inference engine)을 하나 만듭니다. 이름은
`badak`입니다. "밑바닥"의 그 바닥입니다.

추론 엔진은 학습이 끝난 신경망 모델을 받아 실제로 실행하는
소프트웨어입니다. 스마트폰이 사진 속 얼굴을 찾을 때, 노트북에서 언어
모델이 문장을 이어 쓸 때, 그 밑에서 일하는 것이 추론 엔진입니다.
llama.cpp, LiteRT, ONNX Runtime 같은 이름을 들어 보셨다면 그것들이 바로
추론 엔진입니다.

우리는 빈 디렉터리에서 시작해 다음을 차례로 해냅니다.

1. 숫자 배열을 다루는 자료구조를 만들고, 손글씨 숫자를 알아보는 작은
   모델을 돌립니다.
2. 대형 언어 모델(LLM)을 파일에서 읽어 문장을 생성합니다.
3. 그 엔진을 수십 배 빠르게 만들고, llama.cpp와 나란히 놓고 잽니다.
4. 같은 엔진으로 이미지 분류, 음성 인식, 이미지 생성, 음성 합성까지
   돌립니다.
5. 서버로 만들고, 폰과 브라우저로 옮깁니다.

단계마다 실전 엔진과 성능을 비교하고, 차이가 어디서 오는지 따져
봅니다. 이 책의 목적은 실전 엔진을 대체하는 것이 아니라, 실전 엔진이
왜 그렇게 만들어졌는지 이해하는 것입니다.

## 누구를 위한 책인가

AI 인퍼런스 엔지니어링으로 영역을 넓히려는 시니어 소프트웨어
엔지니어를 위해 썼습니다.

**이 책이 전제하는 것**

- 수년간의 프로그래밍 실무 경험
- 자료구조, 운영체제, 컴퓨터 구조의 기본기. 캐시, 스레드, 가상 메모리
  같은 말이 낯설지 않으면 충분합니다.
- 명령줄과 Git 사용

**이 책이 전제하지 않는 것**

- 머신러닝과 딥러닝 지식
- 선형대수와 확률. 필요한 만큼을 [2장](part1/ch02_math.md)에서 코드로 익힙니다.
- PyTorch나 TensorFlow 사용 경험
- SIMD나 GPU 프로그래밍 경험

Rust는 처음이어도 다른 언어 경력이 있으면 따라올 수 있게 썼습니다. 이
책이 쓰는 Rust 기능은 [부록 A](appendix/a_rust.md)에 정리합니다.

## 이 책의 약속

이 책은 다음 원칙을 지킵니다.

**이 책만으로 이해됩니다.** 필요한 배경지식은 모두 책 안에서
설명합니다. 다른 자료를 읽고 와야 하는 대목은 없습니다.

**밑바닥부터 만듭니다.** `badak`은 Rust 표준 라이브러리만 씁니다. 행렬
곱셈도, 모델 파일 파서도, 스레드 풀도 직접 씁니다. 예외는 GPU 접근처럼
추론의 본질이 아닌 경계 부분뿐이며, 그때마다 밝힙니다.

**모든 코드가 실행됩니다.** 본문의 코드는 저장소의 실제 소스 파일에서
끌어온 것입니다. 책에 보이는 코드가 곧 테스트를 통과한 코드입니다.

**수치는 직접 잰 것입니다.** 책의 성능 수치는 모두 한 대의 기계(Apple
M4 Max, 메모리 48GB)에서 직접 측정했습니다. 측정에 쓴 명령과 원시
결과는 저장소에 있어, 여러분의 기계에서 다시 잴 수 있습니다. 직접 재지
못한 것은 그 자리에서 그렇다고 적습니다. "재지 않았습니다", "읽은
것입니다", "계산한 것입니다" 같은 말이 그 표시입니다. 다른 자료에서
가져온 수치에는 출처를 함께 적습니다. 폰의 실기기와 데이터센터의 GPU처럼
이 책이 끝내 재지 못한 것은 [53장](part7/ch53_scorecard.md)에 모아 두었습니다.

여러분의 기계에서는 수치의 절대값이 다를 것이고, 엔진 사이의 순위가
바뀌는 경우도 있을 것입니다. 그 차이를 스스로 설명할 수 있게 되는 것이
이 책의 목표 가운데 하나입니다.

**근거를 남깁니다.** 본문의 주장에는 각주로 근거를 답니다.[^example]
각 장 끝의 "참고 문헌" 절에 그 장의 각주가 모여 있고, [부록 F](appendix/f_references.md)에 책
전체의 문헌을 모았습니다. 소스 코드는 읽은 커밋과 파일과 줄을 적었고,
논문은 **어디까지 읽었는지**를 각주에 적었습니다. 초록까지만 읽은 논문이
많습니다. 더 깊이 들어가고 싶을 때의 출발점으로 쓰십시오.

## 책의 구성

| 부 | 내용 | 끝나면 할 수 있는 일 |
|---|---|---|
| 1부. 기초 | 수학, 신경망, 텐서, 연산자, 모델 파일 | 작은 모델을 처음부터 끝까지 돌린다 |
| 2부. LLM 완주 | 토크나이저, 트랜스포머, KV 캐시, 샘플링 | 언어 모델로 문장을 생성한다 |
| 3부. 성능 | 병목 계산, 행렬 곱, SIMD, 스레딩, 양자화, GPU | 병목을 찾아 엔진을 빠르게 만든다 |
| 4부. 분야별 완주 | 비전, 음성, 임베딩, 이미지 생성, 멀티모달 | 새로운 종류의 모델을 스스로 올린다 |
| 5부. 서빙 | 추론 서버, 배칭, 생성 제어 | 엔진을 여러 사용자가 쓰는 서비스로 만든다 |
| 6부. 온디바이스 AI | 폰, 모바일 가속기, 브라우저 | 엔진을 사용자의 기기로 옮긴다 |
| 7부. 지평 | 프레임워크 배포, ML 컴파일러, 종합 성적표 | 이 분야가 어디로 가는지 판단한다 |

1부에서 3부까지는 순서대로 읽기를 권합니다. 뒤의 장이 앞 장에서 만든
코드 위에 쌓이기 때문입니다. 4부 이후는 관심 있는 분야부터 읽어도
됩니다. 각 장은 기대는 앞 장을 본문에서 번호로 가리킵니다.

## 각 장의 구성

코드를 만드는 장은 대체로 같은 순서를 따릅니다.

1. **문제**: 이 장이 푸는 문제와, 풀기 전의 측정값
2. **개념**: 필요한 배경
3. **구현**: 가장 단순한 구현에서 시작해 단계적으로 개선
4. **검증**: 정답과 수치를 대조
5. **측정**: 벤치마크 결과와 해석
6. **실전 엔진에서는**: 같은 문제를 실전 엔진이 푸는 방식
7. **정리와 연습 문제**
8. **참고 문헌**

우리는 단순한 구현을 지우지 않습니다. 느린 첫 구현과 빠른 최종 구현이
저장소에 함께 남아 있어, 각 최적화가 얼마나 기여했는지 직접 재 볼 수
있습니다.

## 준비물

**컴퓨터.** 이 책의 기준 기계는 Apple Silicon 맥이지만, 코드는 Linux와
x86-64에서도 동작하도록 썼습니다. 다른 환경에서 따라 하는 방법은
[부록 D](appendix/d_x86_linux.md)에 있습니다. 메모리는 16GB 이상을 권합니다.

**Rust.** 최신 안정판을 씁니다. [rustup](https://rustup.rs)으로
설치합니다.

```bash
rustc --version
```

이 책은 Rust 1.100에서 확인했습니다. 에디션은 2024를 씁니다.

**저장소.** 책의 원고와 코드가 한 저장소에 있습니다.

```bash
git clone https://github.com/chosungmann/building-an-inference-engine-from-scratch.git
```

**Python은 선택입니다.** 우리 엔진이 올바른 값을 내는지 확인하려면
정답이 필요하고, 그 정답은 PyTorch로 만듭니다. 이를 위한 Jupyter
노트북을 제공하며, Google Colab에서 바로 열 수 있어 Python을 설치하지
않아도 됩니다. 이 책이 학습해 만든 모델과 정답 파일은 공개된 곳에 올려
두었고 내려받는 스크립트를 함께 제공하므로, 노트북을 전혀 실행하지 않아도
책을 끝까지 따라갈 수 있습니다.
