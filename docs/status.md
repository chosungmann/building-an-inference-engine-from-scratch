# 진행 상황

세션을 시작할 때 이 문서를 먼저 읽고, 장을 끝낼 때마다 갱신합니다.

## 다음에 할 일

**6장. 모델 파일 읽기**를 씁니다.

- safetensors와 GGUF 파서를 만들고, 메모리 매핑으로 가중치를 읽습니다.
  새 크레이트 `badak_formats`를 이 장에서 만듭니다.
- 메모리 매핑은 저장소의 새 종류가 됩니다. 4장의 `Storage`에 "파일에서
  빌린 메모리"를 추가하는 방법을 정해야 합니다. `unsafe`가 처음 등장합니다.
- safetensors의 헤더는 JSON이므로 작은 JSON 파서가 필요합니다. 표준
  라이브러리만 쓴다는 원칙에 따라 직접 씁니다.
- 테스트용 모델 파일은 저장소에 넣을 수 있을 만큼 작은 것을 직접 만들어
  씁니다.

## 3부에서 갚을 빚

장을 쓰면서 "뒤에서 빠르게 만든다"고 약속한 것들입니다. 해당 장을 쓸 때
빠뜨리지 않도록 모아 둡니다.

| 약속 | 나온 곳 | 갚을 곳 |
|---|---|---|
| 단순 행렬 곱 `1024 × 1024`가 0.84초 | 2.5절 | 16~18장 |
| 브로드캐스팅 덧셈이 빠른 길보다 12배 느림 | 5.5절 | 17장 |
| `linear`가 벡터마다 `matvec`을 따로 부름 | 5.3절 | 16장 |
| `Mlp::forward`에 활성화 함수 융합이 없음 | 3.7절 | 24장, 30장 |
| 연산자마다 새 텐서를 할당함 | 5장 전반 | 22장, 26장 |

뜻이며, 저자 검토는 별도로 진행됩니다.

| - | 표지 | 완료 | |
